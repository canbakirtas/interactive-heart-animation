## İnteraktif Kalp Animasyonu

JavaScript (Vanilla JS) ve CSS kullanılarak geliştirilmiş; parametrik kalp eğrisi, dinamik parçacık sistemi ve anlık özelleştirme paneli içeren interaktif bir web arayüzü uygulaması.

## Özellikler

- **Parametrik Kalp Denklemi:** Parçacıkların geometrik yerleşimini matematiksel sinüs ve kosinüs formülleri ile hesaplar.
- **Dinamik Kontrol Paneli:** Animasyon hızını, parçacık yoğunluğunu, ölçeğini ve görüntülenen metni eş zamanlı (real-time) olarak değiştirme imkanı sunar.
- **Özel İmleç ve Etkileşimler:** Özelleştirilmiş imleç tasarımı ve tıklama olaylarında tetiklenen parçacık patlama (burst) animasyonları.
- **Tema Yönetimi:** CSS değişkenleri (`--hue`) aracılığıyla dinamik renk paleti değişimi.

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Custom Properties, Flexbox, Keyframe Animations)
- Vanilla JavaScript (ES6+)
